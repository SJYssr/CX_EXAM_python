# 超星考试客户端工具 🎓

一个强大的超星考试辅助工具，集成了题库搜索、AI问答和自动输入功能，帮助用户更高效地处理考试相关任务。

## 🌟 功能特性

### 📚 题库管理
- **本地题库搜索**：支持从 `tiku.txt` 文件中快速搜索题目和答案
- **关键词高亮**：搜索结果自动高亮显示，便于快速定位
- **内容热重载**：支持动态加载题库内容

### 🤖 AI智能问答
- **双AI支持**：集成讯飞星火和Deepseek两种AI服务
- **腾讯云免费版**：支持腾讯云Deepseek免费API（2025年2月前免费）
- **实时回答**：AI实时生成答案，支持流式输出
- **错误处理**：完善的异常处理机制

### 🎮 智能操作
- **自动输入**：支持将答案自动输入到目标系统
- **延迟输入**：模拟人工输入，避免检测
- **快捷操作**：多种快捷键支持高效操作

### 🖥️ 窗口管理
- **透明度调节**：Ctrl+滚轮调节窗口透明度
- **自由拖拽**：Ctrl+左键拖拽移动窗口
- **大小切换**：F3切换窗口大小模式
- **字体调节**：Alt+滚轮调节文字大小
- **防录屏保护**：自动启用防录屏，F4手动切换（支持Windows 7及以上）
- **输入法保护**：自动识别并保护输入法窗口，防止候选词被录制

## 🛠️ 技术栈

- **框架**：.NET 6.0 + WPF
- **配置管理**：YamlDotNet
- **JSON处理**：Newtonsoft.Json
- **WebSocket**：WebSocketSharp-netstandard
- **AI服务**：讯飞星火 WebSocket API、Deepseek HTTP API

## 📦 安装与配置

### 环境要求
- Windows 7 及以上（推荐 Windows 10/11）
- .NET 6.0 Runtime

### 快速开始

1. **克隆项目**
   ```bash
   git clone [项目地址]
   cd fuck超星
   ```

2. **配置AI服务**
   
   编辑 `config.yaml` 文件：
   
   ```yaml
   # AI服务类型: 0=未设置, 1=Spark, 2=Deepseek
   AI_set:
     type: 2  # 推荐使用Deepseek(腾讯云免费版)
   
   # Deepseek配置 - 腾讯云免费版本
   deepseek:
     api_key: "sk-你的腾讯云API密钥"  # 需要去腾讯云申请
     model: "deepseek-chat"
     api_url: "https://api.lkeap.cloud.tencent.com/v1"
   ```

3. **获取腾讯云API密钥（推荐）**
   - 访问：https://console.cloud.tencent.com/lke
   - 注册腾讯云账号
   - 开通大模型知识引擎
   - 创建API密钥并复制到配置文件

4. **准备题库文件**
   
   将你的题库内容放入 `tiku.txt` 文件中，支持任意文本格式。

5. **编译运行**
   ```bash
   # 编译
   dotnet build
   
   # 或直接运行
   dotnet run
   ```

### 备用AI配置（讯飞星火）

如果需要使用讯飞星火AI，请配置：

```yaml
AI_set:
  type: 1

SPARK:
  Spark_url: "wss://spark-api.xf-yun.com/v3.5/chat"
  api_key: "你的星火API密钥"
  api_secret: "你的星火API密钥"
  appid: "你的星火应用ID"
  domain: "generalv3.5"
```

## 🎯 使用说明

### 基本操作

1. **题库搜索**
   - 在搜索框输入关键词
   - 按回车或点击搜索按钮
   - 使用回车键跳转到下一个搜索结果

2. **AI问答**
   - 点击"AI"按钮切换到AI界面
   - 输入问题并提交
   - 等待AI回答并查看结果

3. **自动输入**
   - 在输入框中输入要发送的文本
   - 点击输入按钮或按回车
   - 系统将自动输入到目标位置

### 快捷键操作

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + 滚轮` | 调节窗口透明度 |
| `Alt + 滚轮` | 调节文字大小 |
| `Ctrl + 左键` | 拖拽移动窗口 |
| `右键` | 快速切换透明度 |
| `F3` | 切换窗口大小模式 |
| `F4` | 切换防录屏状态 |
| `F5` | 调试输入法窗口（枚举并扫描） |
| `回车` | 跳转下一搜索结果 |
| `Esc/F1-F2/F6-F12` | 退出程序 |

### 窗口模式

- **正常模式**：300x533像素，半透明显示
- **最小化模式**：5x910像素，贴边显示，几乎隐形

## 🛡️ 防录屏技术说明

### 不同系统采用的防录屏技术

| 操作系统 | 防录屏技术 | 效果等级 | 说明 |
|----------|------------|----------|------|
| **Windows 10 2004+** | `WDA_EXCLUDEFROMCAPTURE` | ⭐⭐⭐⭐⭐ | 最强防录屏，完全阻止屏幕录制 |
| **Windows 7/8/8.1/10** | `WDA_MONITOR` + DWM排除 | ⭐⭐⭐⭐ | 兼容模式，有效防止大部分录屏 |
| **Windows Vista** | 分层窗口技术 | ⭐⭐⭐ | 基础防录屏，对部分录屏软件有效 |
| **Windows XP** | 不支持 | ❌ | 系统过旧，无法提供防录屏 |

### 技术原理

1. **SetWindowDisplayAffinity API**：通过设置窗口显示关联性，阻止窗口内容被录制
2. **DWM (Desktop Window Manager)**：排除窗口预览，防止通过桌面管理器截取
3. **分层窗口**：设置特殊窗口属性，干扰部分录屏软件
4. **输入法窗口枚举**：实时扫描并保护输入法相关窗口
5. **多种输入法支持**：支持微软、搜狗、QQ、百度等主流输入法

### 输入法保护特性

- **实时监控**：每500ms扫描一次系统中的输入法窗口
- **智能识别**：通过窗口类名和标题识别各种输入法窗口
- **自动保护**：发现新的输入法窗口时自动应用防录屏设置
- **支持的输入法**：
  * 微软拼音输入法
  * 搜狗输入法
  * QQ拼音输入法
  * 百度输入法
  * 讯飞输入法
  * 谷歌拼音输入法
  * 五笔输入法
  * 触摸键盘等

## 🔧 常见问题

### Q: AI服务无法使用？
A: 请检查：
- 网络连接是否正常
- API密钥是否正确配置
- AI服务类型是否设置正确

### Q: 题库搜索不到内容？
A: 请确认：
- `tiku.txt` 文件是否存在
- 文件编码是否为UTF-8
- 搜索关键词是否正确

### Q: 窗口无法拖拽？
A: 请使用 `Ctrl + 左键` 组合键进行拖拽

### Q: 防录屏功能无效？
A: 请检查：
- 操作系统是否为 Windows 7 及以上版本
- 是否以管理员权限运行程序（推荐）
- 使用 F4 键手动切换防录屏状态
- 不同系统防录屏效果可能不同：
  * Windows 10 2004+：最强防录屏
  * Windows 7-10：兼容模式防录屏
  * Windows XP/Vista：不支持或效果有限

### Q: 输入法候选词仍然被录制？
A: 请检查：
- 确保已按 F4 启用防录屏功能
- 查看程序标题栏显示的保护窗口数量
- 某些第三方输入法可能需要添加到支持列表
- 尝试重启程序重新扫描输入法窗口

### Q: 如何查看防录屏状态？
A: 
- 按 F4 键，程序标题栏会显示详细状态信息
- 格式：`防录屏状态 | 输入法保护：状态(保护窗口数)`
- 例如：`防录屏已启用 | 输入法保护：开启(3个窗口)`
