【中文乱码解决方案 / Chinese Encoding Issues】

如果界面出现乱码，请按以下步骤操作：
If you see garbled Chinese text, follow these steps:

步骤1 / Step 1: 系统区域设置 / System Region Settings
  - 按 Win+I 打开设置 / Press Win+I to open Settings
  - 时间和语言 -> 区域 / Time & Language -> Region  
  - 国家或地区：中国 / Country: China
  - 区域格式：中文(简体,中国) / Format: Chinese (Simplified, China)

步骤2 / Step 2: 显示语言 / Display Language
  - 时间和语言 -> 语言 / Time & Language -> Language
  - Windows显示语言：中文(简体,中国) / Windows display language: Chinese (Simplified, China)

步骤3 / Step 3: UTF-8支持 / UTF-8 Support  
  - 控制面板 -> 区域 -> 管理 / Control Panel -> Region -> Administrative
  - 更改系统区域设置 / Change system locale
  - 勾选：Beta版：使用Unicode UTF-8提供全球语言支持
  - Check: Beta: Use Unicode UTF-8 for worldwide language support
  - 重启电脑 / Restart computer

步骤4 / Step 4: 兼容性模式 / Compatibility Mode
  - 右键程序文件 / Right-click program file
  - 属性 -> 兼容性 / Properties -> Compatibility  
  - 兼容模式：Windows 8 或 Windows 10 / Compatibility mode: Windows 8 or 10
